# 樊老师功能播放器

基于 **Screenbox + LibVLC** 改造的原生 UWP 网课播放器。

开发分支：`screenbox-player`

## 开发目标

1. MP4 / H.264 / H.265 / HEVC
2. 本地文件播放
3. SMB 局域网文件
4. 播放列表与自动下一集
5. 收藏文件夹
6. 高级深色护眼播放界面
7. 色温调节
8. 视频智能反色
9. 百分比裁切、移动、缩放、恢复
10. 头像区域遮罩，避免反色影响人物区域
11. 全屏与窗口缩放保持播放定位
12. Windows 展台模式
13. 后续接入天翼云盘 / 百度网盘

## 技术底座

- UWP
- Screenbox
- LibVLC / LibVLCSharp
- XAML + MVVM
- SQLite 播放记录与播放列表

Screenbox 已经提供成熟的播放器架构、播放队列、媒体库、播放进度、网络媒体等基础能力，我们在其基础上开发樊老师网课专用功能，而不是重新实现播放器内核。

## 原浏览器插件

`Archive/EdgePluginV1.0/` 保存之前的天翼云盘 Edge 插件版本，仅作为功能参考和历史存档。

后续播放器中的反色、裁切、遮罩等行为，以该版本的实际效果为参考，但全部改为播放器原生功能。

## 开发原则

- 不再从零实现 UWP 播放内核
- 优先复用 Screenbox 已有能力
- 播放核心与云盘 Provider 分离
- 第一阶段先确保 x64 UWP 可以稳定编译、启动、播放
- 功能逐项增加，每一步都保持可构建
