# Edge 插件 V1.0 存档

这是本项目转向原生 UWP 前的最后可用浏览器插件版本，作为 UWP 播放器功能基准。

原始核心文件保留在：
`MosuanTianyiKiosk/Web/MosuanPlayer.js`

基准功能：
- 智能反色
- C 键随时进入裁切
- 裁切移动/缩放
- 百分比坐标定位
- 全屏/窗口缩放跟随
- 裁切恢复原视频
- A 键头像遮罩
- 遮罩移动/缩放/恢复
- 播放/暂停、快进/快退、倍速、静音

注意：当前 GitHub 连接不能直接上传此前生成的二进制 `mosuan-edge-video-v1.0.zip`，因此先保留可追溯的核心 JS 源文件作为存档；不伪造一个新的 ZIP 代替原版本。
